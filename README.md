# 計算トレーニング5

小学校5年生または中学校2年生から、中学校3年生までの数学を継続して学ぶためのWebアプリです。

## 主な機能

- 小5コース（小5〜中3）と中2コース（中2〜中3）
- 学習者ごとに分離された名前、履歴、連続学習日数
- 81単元（中3は22単元）、基礎・標準・発展の3段階
- 単元ごとの要点、解法ポイント、例題
- 今日のおすすめ学習
- 単元別習熟度と苦手単元の自動推薦
- 20問の総合テスト
- 間違えた問題の解説付き振り返り
- Google Chatなどへ貼り付けられる毎日・週間学習報告
- Clipboard APIと旧Android向け代替コピー
- 任意の試験日・目標正答率に基づく週間判定
- 全角入力、単位、同値分数などに対応した解答判定
- GitHub Pagesへの自動デプロイ

学習履歴と報告データはブラウザの`localStorage`に保存され、外部へ自動送信されません。従来形式の履歴は小5プロフィールへ引き継がれ、報告の週間集計にも利用されます。

## 開発

```bash
npm ci
npm run dev
```

## 品質確認

```bash
npm run check
```

`npm run check`は、全単元・全難易度の問題生成テスト、解答判定テスト、TypeScript型検査、本番ビルドを実行します。

Python 3が必要です。`npm run audit:math`で全24,300問を生成し、うち9,300問の数式・解の整合性をPythonで独立検証します。中3の追加範囲は平方完成、二次方程式の文章題、二次関数の変化の割合と変域、相似条件・平行線・面積比と体積比、三平方の応用、標本の選び方です。自由記述による証明問題の添削や全教科書の網羅には対応していません。
